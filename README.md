# AquaTech

AquaTech is a mobile application developed to improve water service operations by providing a digital platform for technicians and customers. The system is designed to replace manual documentation processes with a more efficient way of managing service requests, technician reports, and customer information.

## Overview

Water service companies often rely on paper-based documentation for recording service activities, which may lead to delays, lost records, and difficulties in monitoring service progress. AquaTech addresses these challenges by providing a centralized mobile application that allows technicians to manage tasks digitally while enabling customers to submit and monitor service requests.

## Features

### Technician Features
- User Authentication
- View and Manage Assigned Service Requests
- Technician Task Monitoring
- Digital Service Reporting
- Customer Information Management
- Upload Customer Identification Documents
- Store Service Records Digitally

### Customer Features
- Submit Service Requests
- Monitor Request Status
- Receive Service Updates
- Provide Feedback

## Technologies

- Java
- Android Studio
- Firebase Authentication
- Firebase Realtime Database
- Firebase Storage

## Requirements

- Android 8.0 or higher
- Internet Connection

## Purpose

AquaTech aims to improve service efficiency by reducing manual paperwork, minimizing documentation errors, and improving communication between technicians and customers through a digital mobile platform.
