# AquaTech

**AquaTech** is a mobile application designed to improve water service operations by providing a digital platform for technicians and customers. It helps reduce manual documentation by allowing service requests, technician reports, and customer information to be managed digitally.

## Overview

AquaTech was developed to address common issues with paper-based service documentation, such as delayed updates, misplaced records, and difficulties in monitoring service activities.

The application provides technicians with tools for managing assigned service requests and submitting service reports, while customers can submit requests, monitor their status, and receive service updates.

## ✨ Features

### Technician

* **User Authentication**
* **Assigned Service Requests**
* **Task Monitoring**
* **Digital Service Reports**
* **Customer Information**
* **Customer ID Upload**
* **Digital Service Records**

### Customer

* **Service Requests**
* **Request Status Monitoring**
* **Service Updates**
* **Feedback**
